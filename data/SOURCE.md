# Tiny Shakespeare provenance

Original corpus: https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt

Source project: https://github.com/karpathy/char-rnn

This file is the Tiny Shakespeare text corpus distributed by Andrej Karpathy's
char-rnn project. The literary source is William Shakespeare's public-domain works.
The upstream repository has no license file at the time of retrieval; this project
does not assert a license for the upstream compilation or code.

The downloaded corpus SHA-256 is recorded in `../outputs/metadata.json`.
